# Security policy

Race Weekend is an unofficial client for F1 TV. Please report security
issues privately; do not disclose vulnerabilities, account information,
pairing codes, access tokens, signed playback URLs, DRM challenges, or license
responses in public issues or discussions.

After this repository is public and GitHub private vulnerability reporting is
enabled, use the **Report a vulnerability** option on the repository's Security page.
Include the affected version, TV/webOS model, impact, and steps to reproduce.
Redact credentials and all account-specific or playback-specific values.

We will acknowledge reports and assess them as time permits. Please allow time
for investigation and a fix before making a report public.

## Supported versions

Only the latest version on the `develop` branch is currently supported for
security fixes. Releases on `main` may lag behind during testing.
